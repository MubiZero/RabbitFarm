# Лендинг rabbitfarm.click

Витрина продукта: четыре статические страницы (русская, таджикская,
узбекская, английская), собранные из одного шаблона и четырёх словарей.

Отдельный сервис, а не страница внутри приложения: человек приходит из
поиска с дешёвого телефона на мобильном интернете, и ему нужны сотни
килобайт текста и картинок, а не мегабайты Flutter-бандла.

## Сборка

```bash
node landing/build.js
```

Зависимостей нет, `npm install` не нужен. Результат ложится в `landing/dist`:

| Адрес | Файл |
|---|---|
| `/` | `dist/index.html` (русский) |
| `/tg/`, `/uz/`, `/en/` | `dist/<язык>/index.html` |
| `/sitemap.xml`, `/robots.txt` | генерируются сборкой |

Посмотреть локально можно любым статическим сервером, например
`python -m http.server 5961 --directory landing/dist`.

## Что где лежит

```
build.js            сборка страниц, карты сайта и robots.txt
src/i18n/*.json     все тексты, по файлу на язык
src/styles.css      стили, палитра взята у приложения
src/app.js          выбор дела в разделе «Что записать», след касания, появление секций
src/og.html         исходник картинки для ссылок в мессенджерах
src/assets/screens  снимки экранов приложения (webp)
src/assets/icons    иконки Phosphor
src/assets/fonts    Onest, подмножества latin и cyrillic
```

## Тексты

Все строки живут в `src/i18n`. Правка текста это правка словаря и пересборка,
шаблон трогать не нужно. Новый язык — новый файл словаря плюс его код в
`LOCALES` внутри `build.js`.

## Снимки экранов

Это настоящие экраны приложения, а не рисунки. Снимаются с запущенного
стенда и складываются в `src/assets/screens` в формате webp шириной 640.
Порядок: поднять `api` и веб-сборку приложения, залогиниться на
демо-ферме, пройти по экранам и сохранить снимки.

## Картинка для ссылок

`src/og.html` это исходник `assets/og.png` (1200×630), той картинки, что
видно при отправке ссылки в мессенджере. Пересобрать:

```bash
node landing/build.js
chrome --headless --window-size=1200,630 \
  --screenshot=landing/src/assets/og.png http://localhost:5961/og.html
node landing/build.js
```

## Адреса кнопок

Кнопка «Открыть приложение» и кнопка «Скачать для Android» берут адреса из
`/config.json`, который контейнер пишет при старте из переменных окружения:

| Переменная | Что задаёт |
|---|---|
| `APP_URL` | адрес веб-версии приложения |
| `ANDROID_APK_URL` | адрес сборки для Android |

Пустой `ANDROID_APK_URL` оставляет кнопку скрытой: пока сборки нет, ссылка
в никуда хуже её отсутствия. Те же правила действуют на странице
приглашения (`mobile/web/i`).
