2. Какие данные собираются

КатегорияЧто именно
Учётная запись Имя, email, телефон (не обязателен), пароль — хранится только в виде хеша, не в открытом виде.
Данные фермы Название и тип фермы; поголовье кроликов, клетки, породы, случки и окролы, вакцинации и лечение, корма и их расход, задачи, заметки, доходы и расходы.
Фотографии Фотографии кроликов, которые пользователь загружает сам.
Данные сотрудников фермы Email или телефон приглашённого сотрудника, его роль на ферме — вводит владелец фермы при приглашении.
Технические данные Токен устройства для push-уведомлений; IP-адрес — в журнале действий службы поддержки и в служебных логах сервера; данные для входа хранятся на устройстве в защищённом хранилище.
Платежи Сумма, статус и номер платежа. Номер карты и другие банковские реквизиты приложение не получает и не хранит — оплата проходит на защищённой странице банка.

3. Зачем эти данные нужны

  • Чтобы вести учёт фермы — это основное назначение приложения.
  • Чтобы присылать уведомления: просроченные вакцинации, задачи, напоминания об оплате тарифа.
  • Чтобы служба поддержки могла посмотреть, что видит пользователь, если он сам об этом попросил — только в режиме просмотра, без права что-либо менять, и каждый такой случай фиксируется в журнале.
  • Чтобы принимать оплату тарифа.

4. Кому передаются данные

Данные передаются только тем, кто нужен для работы самого приложения, и не продаются и не передаются в маркетинговых целях:

  • Firebase Cloud Messaging (Google) — для доставки push-уведомлений на телефон.
  • Payom — для отправки SMS.
  • Банк «Эсхата» (эквайринг) — для приёма платежей; данные карты вводятся на стороне банка, приложению не передаются.
  • Почта и файлы (в том числе фотографии) хранятся на собственной инфраструктуре — третьим лицам не передаются.

5. Сколько хранятся данные

  • Данные фермы хранятся, пока действует учётная запись.
  • При удалении фермы данные становятся недоступны сразу, а физически удаляются вместе с фотографиями через 30 дней — этого времени достаточно, чтобы передумать.
  • Служебные логи сервера хранятся ограниченное время и используются только для устранения неполадок.

6. Права пользователя

  • Посмотреть и исправить — большинство данных редактируется прямо в приложении.
  • Получить копию своих данных — по запросу в поддержку можно получить выгрузку всех данных фермы.
  • Удалить аккаунт и данные фермы — по запросу в поддержку.
  • Отозвать согласие на уведомления — можно отключить push-уведомления в настройках телефона.

7. Безопасность

Пароли хранятся в виде необратимого хеша, соединение с сервером идёт по защищённому каналу (HTTPS), доступ к данным фермы разграничен по ролям сотрудников. Ни один способ хранения данных не даёт стопроцентной гарантии, но мы стараемся ограничивать доступ к данным минимально необходимым кругом лиц.

8. Изменения политики

Если политика существенно изменится, мы предупредим об этом в приложении. Дата вверху страницы всегда показывает, когда документ обновлялся в последний раз.
