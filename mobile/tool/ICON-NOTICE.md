# Происхождение знака

Кролик на иконке приложения и на витрине — иконка `rabbit` из набора
**Phosphor Icons**, лицензия **MIT**. Исходник в виде вектора лежит в
`landing/src/assets/mark.svg`, растр для раскладки по платформам — рядом:
`rabbit-mark-1024.png` (тот же рисунок, линии цветом `#0F172A`, фон
прозрачный). Фон, доли и раскладка — наши, собираются `make_app_icon.py`.

Лицензия разрешает использование, изменение и распространение, в том числе в
коммерческом продукте, при сохранении уведомления. Полный текст:
<https://github.com/phosphor-icons/homepage/blob/master/LICENSE>.

До сентября 2026 на иконке стоял кролик-эмодзи из **Noto Emoji** (Google,
SIL Open Font License 1.1). Заменён не по лицензии, а ради одного знака на
приложение и сайт: эмодзи и контурный кролик витрины выглядели как два
разных продукта. Эмодзи Apple, на которое похож тот кролик в macOS и iOS,
использовать нельзя — их лицензия не разрешает графику приложений.
