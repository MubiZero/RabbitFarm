# Происхождение иконки

Кролик на иконке приложения — эмодзи `🐇` (U+1F407) из **Noto Emoji**
(Google), лицензия **SIL Open Font License 1.1**. Исходный файл лежит рядом:
`rabbit-noto-512.png`; фон и раскладка по платформам — наши, собираются
`make_app_icon.py`.

Лицензия разрешает использование, изменение и распространение, в том числе в
коммерческом продукте, при сохранении этого уведомления. Полный текст:
<https://github.com/googlefonts/noto-emoji/blob/main/LICENSE>.

Почему не эмодзи Apple, на которое кролик похож в macOS и iOS: их лицензия
использование в графике приложений не разрешает. Визуально Noto почти
неотличим, юридически — свободен.
